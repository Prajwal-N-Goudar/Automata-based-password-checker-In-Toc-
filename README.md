# 🔐 Automata-Based Password Strength Checker

A modern Password Strength Checker built using HTML, CSS, and JavaScript based on Deterministic Finite Automata (DFA).

## ✨ Features
- Real-time password strength analysis
- Live DFA visualization
- Weak / Moderate / Strong classification
- Interactive UI design
- Password component analysis table

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript
- SVG

## 🚀 How It Works
The application checks:
- Password length
- Uppercase letters
- Lowercase letters
- Digits
- Special characters

Based on these rules, the system transitions between DFA states:
- WEAK
- MODERATE
- STRONG
